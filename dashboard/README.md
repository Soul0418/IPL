# IPL Auction Intelligence Dashboard

This directory contains the dashboard component of the IPL Player Auction Intelligence project.

## Planned Dashboard Sections

### 1. Auction Overview

- Total players sold
- Total auction spending
- Average auction price
- Highest auction price
- Auction trends by year

### 2. Player Performance

- Runs
- Wickets
- Batting strike rate
- Bowling economy
- Recent performance

### 3. Auction Valuation

- Actual vs predicted auction price
- Model valuation
- Player valuation ranges
- Price bands

### 4. Model Insights

- Feature importance
- Model error distribution
- Performance by auction-price band
- Extreme prediction errors

## Dashboard Goal

The dashboard is intended to provide an interactive interface for exploring IPL auction trends and the machine-learning valuation system.

Potential implementations include Power BI, Tableau, or a Python-based interactive application.
