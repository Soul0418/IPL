# SQL Analysis

This folder contains SQL analysis related to the IPL Player Auction Intelligence project.

The SQL work focuses on querying and analyzing historical auction and player-performance data.

## Analysis Areas

Examples of analysis performed during the project include:

- Player auction history
- Auction price comparisons
- Player performance aggregation
- Team-level auction analysis
- Sold-player analysis
- Historical player statistics
- Distinct player and auction records
- Aggregated performance metrics

## SQL Skills Demonstrated

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- DISTINCT
- Aggregate functions
- CASE statements
- JOIN operations
- Subqueries
- Data filtering
- Analytical queries

The SQL layer complements the Python machine-learning workflow by providing exploratory and analytical views of the underlying data.
